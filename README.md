# VPN Notify Bot

Telegram-бот напоминает администраторам об окончании оплаченной аренды серверов.
Добавление, изменение, продление, архивирование и Excel-статистика доступны через кнопки под сообщениями.
Другие пользователи и групповые чаты полностью игнорируются.

## Локальный запуск (Windows / PowerShell)

Нужен установленный [uv](https://docs.astral.sh/uv/).

```powershell
uv sync --locked
# Только если .env ещё нет:
Copy-Item .env.example .env
```

Заполните `.env`:

```dotenv
BOT_TOKEN=токен_от_BotFather
ADMIN_IDS=первый_Telegram_ID,второй_Telegram_ID
NOTIFY_TIME=12:00
TIMEZONE=Europe/Moscow
REMIND_DAYS=7
NOTIFY_OVERDUE=true
DATABASE_PATH=data/servers.sqlite3
PROXY_URL=http://127.0.0.1:10808
```

ID — числовой ID пользователя, а не номер телефона или `@username`.
Каждый администратор должен открыть чат с ботом и нажать `/start`.
Токен выдаётся в [@BotFather](https://t.me/BotFather).

```powershell
uv run python main.py --check
uv run python main.py
```

Первая команда проверяет конфигурацию и авторизацию Telegram без рассылки.
Вторая запускает бота; оставьте процесс работающим. Остановка — `Ctrl+C`.
Не запускайте одновременно два экземпляра с одним токеном или базой.
Повторный локальный запуск с той же базой завершается с понятной ошибкой до
подключения к Telegram. Блокировка автоматически освобождается при остановке
процесса; удалять служебный файл `*.run-lock.sqlite3` вручную не требуется.
Если сообщение об активном webhook мешает запуску, сначала отключите прежнюю
интеграцию Telegram, которая использует этот токен.

Если самому `uv sync` нужен прокси для загрузки зависимостей:

```powershell
$env:HTTPS_PROXY = 'http://127.0.0.1:10808'
$env:HTTP_PROXY = 'http://127.0.0.1:10808'
uv sync --locked
```

`uv` управляет `.venv` автоматически. Вручную создавать или активировать окружение
не требуется. `.python-version` выбирает Python 3.14; uv при необходимости
устанавливает его. Код требует Python 3.11 или новее.

## Настройки и сервер

Настройки загружаются из `.env` рядом с `main.py`, независимо от текущего каталога.
Изменения применяются после перезапуска. `PROXY_URL` поддерживает HTTP и SOCKS5;
для прокси с авторизацией используйте `http://user:password@host:port` (специальные
символы в имени и пароле кодируйте как URL). Пустое значение означает прямое
подключение: системные `HTTP_PROXY` / `HTTPS_PROXY` не влияют на Telegram-сессию.

На сервере скопируйте проект, выполните `uv sync --locked`, создайте `.env` и
задайте `PROXY_URL=`. `.env` и файл базы не находятся в Git — перенесите их
отдельно, если нужны те же данные. Остановите локальный экземпляр перед запуском
серверного. Для постоянной работы используйте менеджер процессов сервера.

Пример подготовки на Linux (копирование `.env.example` — только при отсутствии `.env`):

```bash
uv sync --locked
cp .env.example .env
# Заполните BOT_TOKEN, ADMIN_IDS; оставьте PROXY_URL= пустым.
uv run python main.py --check
uv run python main.py
```

## Использование

- `/start` — главное меню, сбрасывает незавершённый ввод.
- «Добавить сервер» — название, хостер, сайт, IP-адрес, домен, начало и конец оплаченного периода.
- «Изменить сервер» — список серверов, карточка, изменение каждого поля и архивирование.
- «Мои сервера» — обзор сроков оплаты и просрочки, переход к карточке сервера.
  Список отсортирован по дате окончания: сначала просроченные и ближайшие сроки,
  затем более поздние. Сортировка применяется до разделения на страницы.
  Кнопки серверов на каждой странице идут по алфавиту без учёта регистра и
  начальных флагов/эмодзи; они открывают те же серверы, что показаны в тексте страницы.
- В карточке — «Продлить», «Редактировать», «Скачать статистику», «В архив»; отдельные поля находятся в подменю редактирования.
- «Продлить» — ввод новой даты окончания и суммы оплаты; сохраняется только после «Сохранить». Кнопка «Продлил» в напоминании открывает ту же форму.
- «Статистика» — Excel по всем серверам или одному, включая удалённые.
- «Отмена» или `/cancel` — выход без изменения сохранённых данных.

Для новых серверов IP-адрес и домен обязательны. Принимаются IPv4 и IPv6 без
порта/маски подсети; домен вводится без `https://` и пути, например
`vpn.example.com`. Домены с кириллицей также поддерживаются и сохраняются
в формате IDNA. Оба поля можно изменить в карточке сервера; они отображаются
в карточке и уведомлениях.

При первом запуске обновлённой версии существующая база автоматически получает
два новых пустых поля. Серверы, даты, версии записей и история уведомлений
сохраняются. У старых серверов IP и домен отображаются как «не указан»; заполните
их через «Изменить сервер». Их можно вводить по отдельности; продление и изменение
старых записей доступны до заполнения этих полей. Повторный запуск не очищает значения.

Все даты вводятся как `ДД.ММ.ГГГГ`. Дата окончания включительна: просрочка
начинается на следующий день. Напоминания приходят ежедневно в указанном
часовом поясе, начиная за `REMIND_DAYS` дней до окончания. При
`NOTIFY_OVERDUE=true` просроченный сервер продолжает напоминать о себе.
Призыв продлить выделен жирным на отдельной строке. В каждом уведомлении есть
«Отказаться»: сообщение меняется на подтверждение с датой окончания оплаты.
«Отмена» возвращает исходное уведомление с кнопками «Продлил», «Открыть хостер»
и «Отказаться».
Кнопка «🌐 Открыть хостер» в уведомлении открывает сайт из карточки сервера.
При пустом списке бот предлагает добавить первый сервер. Ошибка ввода не
сбрасывает форму: исправьте текущее поле и продолжайте с сохранёнными значениями.

При добавлении и продлении введите сумму в рублях: `1500`, `1500,50` или `1500.50`.
Допустима нулевая оплата. Суммы хранятся точно, в копейках. Каждое продление
добавляет отдельный оплаченный период: если прежняя оплата заканчивается
10 октября включительно, новый период начинается 11 октября. Начало аренды
остаётся первоначальным. Карточка показывает последний оплаченный период,
его стоимость и общую сумму известных оплат.

Период, оплаченный бонусами, помечается «Оплачено бонусами» в карточке и в отдельной
колонке истории Excel; денежный расход остаётся равен нулю. Исправление сведений
или повторный ввод нулевой стоимости сохраняет пометку; изменение суммы её снимает.
Обычное продление, в том числе с нулевой стоимостью, не получает пометку автоматически.

«Редактировать» исправляет сведения без добавления платежа: начало аренды
изменяет начало первой записи, окончание — конец последней, стоимость —
сумму последнего периода. Границы соседних периодов сохраняются. Ранее
оплаченные периоды доступны в выгрузке.

«В архив» в карточке также запрашивает подтверждение; «Отмена» возвращает карточку.
После подтверждения сервер остаётся активным до конца оплаченного периода,
в карточке появляется отметка о запланированном архивировании, а напоминания
прекращаются. Намерение хранится в SQLite и сохраняется после перезапуска.
Успешное продление отменяет запланированное архивирование; исправление полей
сохраняет его и использует актуальную дату окончания оплаты.
На следующий день после окончания оплаты сервер автоматически уходит в архив
по часовому поясу `TIMEZONE`. Проверка выполняется каждые 30 секунд независимо
от времени рассылки, а также перед обработкой команд и кнопок. Если бот был
выключен, перенос выполняется после запуска. Если период уже закончился,
подтверждение сразу переносит сервер в архив.
Миграция базы добавляет флаг без изменения существующих серверов и истории.
Старые кнопки «Удалить» также открывают подтверждение отложенного архивирования.
В архиве сервер нельзя редактировать и продлевать, но история и суммы остаются в «Статистике».
Общий `.xlsx` содержит вкладки «Сводка», «Активные», «Удалённые», затем отдельную
вкладку каждого сервера. Отдельная выгрузка содержит сведения сервера, его периоды
и итог. Текст Excel очищается от эмодзи; названия вкладок ограничены 31 символом
для совместимости с Excel. В сообщениях Telegram эмодзи сохраняются.
Скачивание доступно только администраторам в личных чатах.
Если у архивной оплаты даты неизвестны, в Excel отображается «не указан»;
известная сумма включается в общий расход без выдуманного периода.

Карточка «Статистика» показывает известные расходы за всё время по всем серверам,
включая архив и все страницы списка: общий итог, расходы активных и архивных
серверов, их количество, число периодов и оплат бонусами. Периоды без суммы
считаются отдельно, а при их наличии итог помечается как неполный.
Кнопка «📥 Скачать по всем серверам» выгружает всю историю; «🟢 Активные серверы»
и «🗃 Архивные серверы» открывают отдельные списки по 10 серверов на странице
для скачивания истории конкретного сервера. Из каждого списка можно вернуться
к общей статистике или в главное меню.
Во всех списках выбора серверов кнопки располагаются по две в строке;
длинные названия на кнопках сокращаются до 30 символов.

Меню, карточки и формы обновляются в одном сообщении бота. Обработанный ввод
администратора удаляется после показа следующего шага или ошибки ввода;
если Telegram не разрешает удалить сообщение, форма продолжает работать.
Напоминания и файлы Excel сохраняются отдельными сообщениями. После успешной
выгрузки бот размещает новую панель управления под файлом и снимает кнопки
с прежней панели. После перезапуска первый переход по кнопке меню использует
её сообщение; ввод команды создаёт новую панель.

Если показ следующего вопроса формы прервался из-за ошибки связи, следующее
сообщение только восстанавливает текущий вопрос. После этого введите ответ
ещё раз; ранее принятые значения сохраняются.
Дата удаления в Excel отображается в часовом поясе `TIMEZONE`.

При первом запуске версии с историей оплат текущий период каждого существующего
сервера становится первой записью со стоимостью «не указано». Если известна его
стоимость, заполните её до следующего продления через «Редактировать».
Неизвестные суммы не считаются нулевой оплатой; неполные итоги явно помечены.
Уже затёртые периоды восстановить из текущей базы нельзя.

Нажатие «Продлил» и незавершённый ввод не приостанавливают рассылку. Новая дата
должна быть позже старой и не раньше сегодняшней. Начало аренды при продлении
не меняется; его можно исправить отдельно. Если новый срок всё ещё попадает
в окно предупреждения, напоминания продолжаются.

У администраторов отдельные черновики и общий список серверов. Если другой
администратор уже изменил запись, старое действие не сохранится — нужно открыть
актуальную карточку. После перезапуска незавершённый ввод сбрасывается, а серверы
и история успешной доставки сохраняются. После запуска позже времени рассылки
бот отправит напоминания за текущий день; за все пропущенные дни не отправляет.
Проверка выполняется каждые 30 секунд; доставка нескольких серверов может
занимать больше времени из-за ограничений Telegram.

## Данные и проверки

Данные находятся в `data/servers.sqlite3`. Для резервной копии остановите бота и
скопируйте этот файл. Не удаляйте базу при обновлении кода. Токен и прокси-пароли
не записываются в логи. `.env`, базы, `.venv` и логи исключены из Git.

```powershell
uv run python -m unittest discover -s tests -v
uv pip check
```

Тесты используют настоящую SQLite и Dispatcher aiogram; только Telegram API
заменяется тестовой сессией, поэтому тесты не отправляют сообщений людям.
В крайне редком случае аварийного завершения после отправки в Telegram,
но до записи доставки в SQLite возможно повторное напоминание.
